# Katalog-Sets

Legt in einem Base-Katalog automatisch Mehrstück-Sets (2er/3er) für Einzelprodukte an,
inklusive Titel, Beschreibung (KI) und Set-Bild. Läuft zeitgesteuert über GitHub Actions.

Einstellungen und Zugangsdaten liegen ausschließlich in den Repository-Secrets
(`ENV_FILE`, `PROFILES_YAML`, `LOG_PASSWORD`), nicht im Code.
